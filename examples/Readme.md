# Examples

This directory contains usage examples for the Kirby Push Notifications plugin.

These examples are **not part of the plugin API** and are intentionally project-specific.  
They are meant to demonstrate what you can build with the plugin, not how you must use it.

## Philosophy

The plugin takes care of:

- Subscription management
- Channel handling
- Sending notifications

Everything else, workflows, permissions, triggers, is entirely up to your project.

## What you'll find here

Each example shows a different use case, for example:

- Editorial workflows (approval flows, internal notifications)
- Public subscribe buttons
- Developer alerts (exceptions, errors)

They combine Kirby features like:

- `panel.viewButtons`
- Hooks
- Blueprints
- Custom logic

## Important

These examples are meant as inspiration.  
You will likely need to adapt them to your own project.
